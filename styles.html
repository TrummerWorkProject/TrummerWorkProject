🧭 Navbar - Barra de Navegación

Estructura del Navbar

El navbar de TrummerWork incluye un menú hamburguesa responsive automático. Aquí está la estructura básica:

HTML
<nav class="navbar navbar-azul">
  <input type="checkbox" id="nav-check" class="nav-check">
  <img class="navlogo" src="logo.png" alt="Logo">
  
  <!-- Botón hamburguesa -->
  <div class="nav-btn">
    <label for="nav-check" class="nav-btn-label">
      <span class="nav-btn-icon"></span>
    </label>
  </div>
  
  <!-- Links de navegación -->
  <div class="navbar-nav">
    <a href="#" class="nav-link">Inicio</a>
    <a href="#" class="nav-link">Acerca</a>
    <a href="#" class="nav-link">Contacto</a>
  </div>
</nav>

Clases del Navbar

  • .navbar - Contenedor principal del navbar
  • .navbar-negro / .navbar-azul / .navbar-verde / .navbar-rojo / .navbar-amarillo - Colores del navbar
  • .navbar-marca - Texto de la marca/logo
  • .navlogo - Logo/imagen del navbar
  • .navbar-nav - Contenedor de los links de navegación
  • .nav-link - Links individuales de navegación
  • .nav-check - Checkbox para el menú hamburguesa (mobile)
  • .nav-btn - Botón hamburguesa
  • .nav-btn-icon - Icono animado del hamburguesa

💡 Nota sobre el Navbar

El navbar incluye un sistema de menú hamburguesa que se activa automáticamente en pantallas móviles (max-width: 768px). El checkbox controla la visibilidad del menú sin necesidad de JavaScript. SIEMPRE usar esta estructura para garantizar una correcta funcionalidad.

🎠 Sliders

Slider Principal (.tw-slider)

El slider principal ocupa toda la pantalla y soporta imágenes de fondo con texto superpuesto.

  • Slide Izquierda Superior

    Posición: .tsli-lefttop

  • Slide Centrado

    Posición: .tsli-center

  • Slide Derecha Inferior

    Posición: .tsli-rightdown

Clases disponibles:

  • .tw-slider - Contenedor principal del slider
  • .tw-slider-dots - Añade indicadores de puntos
  • .tw-slider-fade - Transición con efecto fade
  • .tw-slider-zoom - Efecto zoom en las imágenes
  • .slider-track - Contenedor de las slides
  • .slide - Cada slide individual
  • .slider-prev / .slider-next - Botones de navegación
