## ¿Qué es esto?
TrummerWork es un framework de diseño y desarrollo orientado a quienes buscan un equilibrio entre **rendimiento y sencillez**. A diferencia de otros frameworks pesados, TrummerWork prioriza una arquitectura modular basada en **diseño atómico**. 

Este proyecto no intenta ser "el próximo framework masivo", sino una herramienta robusta, eficiente y educativa para proyectos web que necesitan velocidad y una estructura limpia sin complicaciones innecesarias.

> "No soy un desarrollador senior con mucha experiencia, y precisamente esa es mi mayor ventaja. Sé exactamente qué se siente estar confundido mirando una pantalla llena de código por primera vez, y diseñé TrummerWork para ser la guía amigable que me hubiese gustado tener." — **Jeremy Diaz, Fundador.**

## Tecnologías
* **Core:** CSS y JavaScript nativo optimizado.
* **Arquitectura:** Diseño Atómico (Atomic Design).
* **Compatibilidad:** Diseñado para integrarse en cualquier flujo de trabajo HTML/JS moderno.

## 💻 Instalación

### Opción A: CDN (Recomendado)
Copia estas líneas en tu proyecto para empezar en segundos.

**En tu `<head>`:**
```html
<link rel="stylesheet" href="[https://trummerwork-project.web.app/style.css](https://trummerwork-project.web.app/style.css)"> 
```

**Antes de terminar tu `</body>`:**
```html
<script src="[https://trummerwork-project.web.app/script.js](https://trummerwork-project.web.app/script.js)"></script>
```

### Opción B: Trabajo Local
Si prefieres tener el control total para editar y modificar, puedes descargar los archivos base directamente desde nuestra web:

[👉 Descargar TrummerWork](https://github.com/TrummerWorkProject/TrummerWorkProject/releases/tag/v1.5.0)
